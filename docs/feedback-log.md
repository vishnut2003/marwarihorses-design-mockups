# Client feedback log

## 2026-10-30 — Home page v1

**Client said (via Web Spider Solutions):** "This is not looking premium look. I want a premium look."

**Our read:** v1 is a dark, gold-bordered, card-heavy layout. It reads as a polished template rather than a luxury brand. The client wants restraint and an editorial, high-end feel.

**Reference supplied by client:** https://coolmore.com/en/ireland/ ("follow this design pattern").

**Response:** Home page v2 built as a new direction following the Coolmore pattern:
- Deep navy canvas with a different dark shade per section (client asked for "variant dark colours for all sections"), white text, muted tan accent.
- Hero with centred crest, italic tagline, rule, short copy, two pill buttons over video.
- "Our Horses" showcase slider with oversized name and 1/6 counter, About with statement and large photo, farm film block, oversized stats, honours quote carousel, hairline news rows, Keep in Touch, Visit with map, location-led footer.
- Poppins Light display type, Inter labels. Pill buttons and circular controls as on the reference.
- v1 stays frozen in `home/v1/` for comparison.

## 2026-10-30 — Home page v2, in-progress feedback

- "Use variant dark colours for all sections." → each section on its own shade.
- "Make the hero more attractive, overlay darker." → navy multiply tint, vignette, label, facts strip.
- "Instead of dark blue, make it black. Use a premium black everywhere." → entire palette moved to a warm near-black family; tan accent kept.

## 2026-11-02 — Home page, v1 chosen over v2

**Client said (via Web Spider Solutions):** Client liked the v1 design, but needs one little change: the heading and paragraph content of the v2 hero section should be added to the v1 hero section.

**Our read:** The v1 layout (dark brown, gold, stats strip) is the approved direction. Only the hero copy changes, taking the v2 wording: heading "House of Finest Marwari Horses" and the paragraph "Breeding Marwari horses of uncommon grace, strength and character. Home to more than eighty horses and a growing record of show-ring champions."

**Response:** Home page v3 created as a copy of v1 with only the hero heading and paragraph replaced. Heading keeps v1's type treatment ("Marwari" in gold italic, two lines). v1 and v2 stay frozen for comparison.
